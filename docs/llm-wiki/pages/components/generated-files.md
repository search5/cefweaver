# 생성되는 파일

`python tools/gen/generate.py`가 쓰는 파일 다섯 개입니다. 모두 저장소에 **커밋**되고 직접 고치지 않습니다. 각 파일 맨 위에 `Generated from CEF <버전>`과 `GENERATED by tools/gen/generate.py. DO NOT EDIT.`가 적혀 있습니다.

| 파일 | 줄 수 | 내용 |
| --- | --- | --- |
| `native/cefwrapper/generated/cefweaver_proxies.h` | 약 960 | 핸들러(클라이언트 쪽 클래스)마다 함수 포인터 표 `Cw<이름>Callbacks`, 프록시 `Cw<이름>Proxy`, 전달 클래스 `Cw<이름>Forward` |
| `cefweaver/cef_api.pxd` | 약 550 | Cython 선언: `CefRefPtr`, `CefString`, 열거형, 범위 안 클래스의 C++ 선언, 전역 함수, 프록시와 표 |
| `cefweaver/cef_api.pxi` | 약 4,150 | 라이브러리 클래스의 `cdef class` 래퍼와 `_wrap_*`, 핸들러의 Python 기반 클래스와 트램펄린, `_g_make_*`, `_g_export_*`, 전역 함수, `__generated_all__` |
| `cefweaver/types.py` | 약 1,870 | 열거형(`IntEnum`, `IntFlag`)과 값 타입(`NamedTuple`). 순수 파이썬이고 `cefweaver.types`로 불러옵니다([types 모듈](../reference/types-module.md)). |
| `cefweaver/_cefweaver.pyi` | 약 1,800 | 타입 스텁. `tools/gen/handwritten.pyi`(손으로 쓴 `CefApp` 부분)를 앞에 붙입니다. |
| `docs/llm-wiki/pages/reference/coverage-report.md` | 약 230 | 커버리지 보고서. 위키 페이지로 쓰이며(`generated: true`) 내용이 같으면 `updated`를 유지합니다. |

(줄 수는 154 배포본에서 생성한 시점의 값입니다.)

## 새로 고치고 확인하기

```sh
python tools/gen/generate.py            # 갱신
python tools/gen/generate.py --check    # 최신인지 확인 (아니면 종료 코드 1)
python tools/gen/generate.py --report   # 보고서만 출력
```

`tests/test_generator.py`가 `--check`와 같은 비교를 하고(`test_generated_files_are_up_to_date`), 같은 입력으로 두 번 생성했을 때 결과가 같은지(`test_generation_is_deterministic`)도 확인합니다. 파일은 LF 줄바꿈으로 씁니다.

## 각 파일의 쓰임

- `cefweaver_proxies.h`는 확장 모듈을 컴파일할 때만 쓰이는 헤더 전용 파일이며 `libcefwrapper.a`에는 들어가지 않습니다. `pyproject.toml`의 `include-dirs`에 `native/cefwrapper`가 있어서 Cython이 `"generated/cefweaver_proxies.h"`로 포함합니다.
- `cef_api.pxd`는 앞선 선언(forward declaration) 블록으로 클래스끼리의 상호 참조를 풀고, 이어서 라이브러리 클래스는 본체(메서드 선언, 모두 `nogil`)를, 핸들러 클래스는 빈 본체를 선언합니다. 열거형은 `ctypedef enum <C 이름>: pass`로 선언하고 생성 코드가 `<enum>값`으로 캐스트합니다.
- `cef_api.pxi`의 맨 앞에는 공통 도우미(`_g_std`, `_g_cef`, `_g_str`, `_g_report`, `_g_release`)와 API 해시 검사가 있습니다.
- 생성된 공개 이름은 `__generated_all__`에 모이고 `_cefweaver.pyx`의 `__all__`에 합쳐집니다.

생성기가 쓰는 입력은 `build/native/cef/include`(사용 중인 배포본의 헤더)입니다. 그러므로 CEF 버전을 바꾸면 반드시 다시 생성해야 합니다([CEF 버전 올리기](../procedures/update-cef-version.md)).
